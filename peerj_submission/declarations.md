## Data availability

The trial-level paired dataset, the controller definitions, the frozen scoring rule, the endpoint definitions and the analysis code are archived at Zenodo (DOI: 10.5281/zenodo.XXXXXXXX) and at https://github.com/Javad-Alizargar/locked-paired-validation-therapy-controllers (release v1.0.0).

## Code availability

The analysis is reproducible from a single entry point. `peerj_analysis/run_all.py` regenerates every table and figure from the committed trial-level data with a fixed random seed. Figure files are provided separately as `Figure 1.png` to `Figure 5.png`.

## AI disclosure

A large language model was used to assist with drafting and editing the manuscript text and to help structure the analysis code. All numerical results were generated by executing the analysis code on the committed data, and the author verified every reported statistic against the program output.
